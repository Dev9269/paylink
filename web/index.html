    How it works

    A three-step escrow flow, on-chain.

    • 1

      Create

      Merchant calls create(link_id, payee, asset, amount) and gets a shareable link.

    • 2

      Fund

      Payer opens the link and calls fund(link_id, payer), locking funds into escrow.

    • 3

      Claim

      Merchant calls claim(link_id) to release funds; Funded / Claimed events stream live.

    The contract

    Written in Rust with soroban-sdk 27. Deployed on Stellar testnet.

    // escrow: create → fund → claim  (events: Funded, Claimed)
create(link_id, payee, asset, amount) // merchant
fund(link_id, payer)                  // customer locks funds
claim(link_id, payee)                 // merchant releases

env.events().publish((Funded,  payer, amount));  // streamed live
env.events().publish((Claimed, payee, amount));  // streamed live
